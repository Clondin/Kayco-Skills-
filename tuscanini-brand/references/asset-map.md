## Bundled Site Assets

`assets/site-assets/` contains a curated GitHub-friendly copy of Tuscanini site imagery from:

`C:\Users\clond\Tuscanini-Site-\public\assets`

Selection rule: JPG, JPEG, and PNG files up to 1 MB each were copied with their relative folders preserved. This provides real Tuscanini product images, ad banners, gallery images, and category assets without committing the multi-gigabyte 360 GIF and MP4 library.

Use these bundled folders first for most brand outputs:

- `assets/site-assets/ads/` for campaign banners and ad references.
- `assets/site-assets/gallery/` for product, lifestyle, and category-specific imagery.
- `assets/site-assets/Pasta/`, `Sauces/`, `Olive Oil/`, `Vinegar/`, `Tuna/`, `Beverage/`, `Frozen/`, `Chips/`, `Crackers/`, and similar category folders for packshots.
- SKU-named files when the user provides a product number.

Large excluded media remains available only from the local site source unless Git LFS or another large-asset storage approach is added:

- `360\*.gif`
- `videos\*.mp4`

## Selection Rules

- Prefer exact SKU or product-family assets over generic Italian food images.
- Prefer `assets/site-assets/` when it contains the needed product or campaign image.
- Prefer product shots for retail/ecommerce and glamour/lifestyle shots for campaigns or presentation covers.
- Prefer source packaging files for package-dependent design decisions.
- If only folder names are available, explain that synced files are needed for exact asset placement.
- Do not move or modify source assets in the KAYCO folder; copy into the working project when needed.
